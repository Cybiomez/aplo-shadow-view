# Журнал решений и осознанных упрощений

## 2026-08-27 — старт проекта

### Архитектура
- **Локальный режim (v1).** Программа работает на самом сервере и показывает
  локальные сеансы. Имя сервера читается автоматически (`COMPUTERNAME`), не
  выбирается из списка. Причина: централизованного управления машинами нет —
  удалённый выбор сервера (`quser /server`, `mstsc /v`) отложен. Код держит
  адрес сервера параметром, чтобы удалённый режим добавлялся без перестройки.
- **Стек из MyCeliumNeuro**: Python-бэк + вебвью-фронт (Vite/TS/SCSS),
  PyInstaller в один переносимый файл. Бэк проще: без туннелей, вместо них —
  системные вызовы RDS и правка реестра.
- **Без трея.** Это администраторская утилита по требованию, а не фоновый
  сервис; обычное окно, закрытие = выход.
- **Память геометрии окна.** Размер, позиция и максимизация/полный экран
  сохраняются в settings.json и восстанавливаются при запуске — окно встаёт
  как оставили. Подписка на события pywebview обёрнута в guard (набор событий
  зависит от версии/платформы); мусорные координаты свёрнутого окна отбрасываются.

### Безопасность
- **Политика теневого доступа по умолчанию — «с подтверждением пользователя»**
  (реестр `...\Terminal Services\Shadow` = 1). Кнопки просмотра/управления
  подключаются БЕЗ `/noConsentPrompt` — пользователь разрешает на своём экране.
- **Экстренный режим** временно ставит `Shadow` = 2 (без подтверждения) и сразу
  создаёт **одноразовое задание планировщика от SYSTEM**, возвращающее `Shadow`
  = 1 через N минут (по умолчанию 15). Возврат гарантирован даже при падении
  приложения — это и есть требование «системный таймер, не зависящий от
  программы». Активный режим виден на главном экране (плашка + отсчёт): дыру в
  контуре безопасности не прячем.
- **Смена значения Shadow не роняет живые теневые соединения** — реестр читается
  только при инициации нового сеанса. Значит авто-возврат безопасен.
- **Аудит.** Все действия (просмотр/управление/отключение/выход/вкл-выкл
  политики) пишутся в локальный журнал: время, администратор, действие, целевой
  пользователь и сеанс. Плюс штатный журнал Windows
  `TerminalServices-RemoteConnectionManager`.
- **Пароли** не хранятся и не запрашиваются — по определению задачи.
- Требуются права администратора (manifest `requireAdministrator`).

### Осознанные упрощения (хвосты)
1. **WebView2 — подтверждён.** На живом Windows Server 2025 окно вебвью
   рисуется штатно (проверено на сборке v0.1.0-dev.2, 27-08-2026) — среда
   WebView2 предустановлена, fixed-version рантайм вшивать НЕ нужно. Хвост закрыт.
2. **Иконка exe** пока не задана (нет `.ico`) — добавить позже.
3. **Только локальный сервер** — удалённый режим отложен (см. Архитектуру).
4. **Windows-only действия.** На Linux собирается и показывает интерфейс, но
   RDS-вызовы возвращают заглушку — для отладки вида, не для работы.
5. **Проверка предусловий на сервере** (реестр Shadow разрешён, включено правило
   файрвола `RemoteDesktop-Shadow-In-TCP`) — программа при старте проверяет и
   подсказывает; авто-настройку файрвола пока не делает.


## 2026-08-27 — v2 (удалённый режим), решения по ходу

- **Движок для Server 2012: CEF отклонён.** `cefpython3` застрял на Python 3.7,
  на нашем 3.12 не работает — тащить нельзя. Решение: **fixed-version WebView2**,
  вшитый в сборку (покрывает Server 2012 **R2**, Win7+). Чистый 2012 (не R2)
  WebView2 не поддерживает вообще — уточнить у Алексея, есть ли такой в парке;
  если только R2 — вопрос закрыт. Заложить в сборку на этапе CI (Windows).
- **Удалённые команды нативные.** `quser /server`, `mstsc /v`, `tsdiscon /server`,
  `logoff /server` — все принимают адрес сервера, Invoke-Command не нужен.
  Реестр Shadow удалённо — `winreg.ConnectRegistry(\\ИМЯ)`; задание-возврат
  удалённо — `schtasks /s ИМЯ` (локально — PowerShell Register-ScheduledTask).
- **Опрос только выбранного.** При входе не опрашивается ничего; `poll_servers`
  бьёт параллельно (ThreadPoolExecutor) только по переданным серверам, у каждого
  свой таймаут; `probe` различает «пусто» и «недоступен».
- **Экстренный режим в мультирежиме — пока локальный.** Тумблер в настройках
  работает на локальном сервере (""). Per-server экстренный (иконка на строке
  сервера) — хвост v2, доделать.
- **`prompt()` для ввода имён** в управлении реестром — работает в браузере/dev;
  в окне WebView2 может не отрисоваться. Если так — заменить на inline-поле.
  Проверить на живой сборке.
