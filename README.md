# AploShadowView

Небольшая переносимая программа для администратора терминального сервера (RDS):
показывает список пользователей в системе и одним кликом даёт теневое
подключение к их сеансу, без запроса и хранения паролей.

## Зачем

На серверах удалённых рабочих столов нередко нужно зайти в сеанс пользователя —
поправить Outlook, помочь с программой. Идти к человеку ради мелочи неохота, а
пароли мы принципиально не храним и не спрашиваем (контур безопасности:
потеряли — меняем). Штатная возможность RDS — теневое подключение (shadowing) —
решает это, но вручную требует возни: `quser`, найти ID сеанса, подставить в
`mstsc /shadow`. AploShadowView прячет это за списком с кнопками.

## Что умеет

- Список пользователей в системе, только имена + состояние сеанса; сам
  обновляется раз в минуту, есть кнопка ручного обновления.
- На каждой строке четыре действия, все с подтверждением:
  - **Просмотр** — теневое подключение только смотреть (`mstsc /shadow:<id>`);
  - **Управление** — с управлением (`mstsc /shadow:<id> /control`);
  - **Отключить** — отключить сеанс, программы продолжают работать (`tsdiscon`);
  - **Выход** — полный выход пользователя (`logoff`).
- По умолчанию теневой доступ идёт **с подтверждением пользователя** (он видит
  запрос на своём экране).
- В настройках — **экстренный режим**: временно разрешить подключение без
  подтверждения. Возврат к обычному режиму гарантирует **задание планировщика от
  SYSTEM** — сработает даже если программа закрыта или зависла. Пока режим
  активен, на главном экране висит плашка с обратным отсчётом.
- Все действия пишутся в локальный журнал (кто, когда, что, с кем).
- Обновление по каналам latest/dev из релизов GitHub: проверка, скачивание,
  установка поверх с закрытием работающей копии.

## Платформа

Целевая — **Windows Server 2025** (и любой современный Windows). Переносимый
исполняемый файл, без установки. На Linux можно смотреть интерфейс и отлаживать
(действия RDS там не работают — это Windows-only).

## Стек

- **Frontend** (вид): Vite + TypeScript + SCSS в окне вебвью.
- **Backend** (логика): Python — окно `pywebview`, вызовы `quser`/`mstsc`/
  `tsdiscon`/`logoff`, реестр и задание планировщика для политики, апдейтер.
- Сборка: PyInstaller в один файл, CI по тегу `v*` (Windows + Linux).

## Запуск из исходников (разработка)

```bash
cd frontend && npm install && npm run build && cd ..
pip install -r backend/requirements.txt
python main.py
```

Отладка одного вида (без Python, с мок-данными): `cd frontend && npm run dev`.

## Данные и настройки

Настройки (канал обновлений, таймер экстренного режима) и журнал — в локальной
папке: `%APPDATA%\AploShadowView\` (Windows) или `~/.config/aplo-shadow-view/`
(Linux). Паролей приложение не хранит и не запрашивает.
