## [Не выпущено]

## [0.2.1] — 2026-08-28

### Исправлено
- Локальная учётная запись серверов (net use + формат ХОСТ\\логин; RPC не читает Credential Manager).
- Сравнение версий: dev-номер сравнивается численно (dev.12 > dev.9), а не строкой.
- Самообновление на Windows: запуск через explorer, без ошибки родительского процесса и чёрных окон.
- Множество правок UI: кастомные выпадающие списки (стилизованы полностью), окна подтверждения поверх, drag&drop серверов, мгновенное снятие галочки, асинхронный опрос раз в 10 сек.

### Изменено
- «Экстренный режим» → «Режим неограниченного доступа»: глобальный флаг /noConsentPrompt для всех серверов (Shadow на серверах — через GPO).

## [0.2.0] — 2026-08-28

### Добавлено
- Два режима: «Локально» (сеансы этого сервера) и «Менеджер» (серверы локальной
  сети, добавляются вручную).
- Реестр серверов, учётные записи (профили и свои данные) с хранением паролей в
  Windows Credential Manager, назначение учёток серверам, проверка доступности.
- Отображаемое имя сервера, показ IP по желанию.
- Импорт/экспорт списка серверов и отдельных серверов файлом (без паролей).
- Асинхронный опрос раз в 10 сек (список не мигает), поиск, сортировка тремя
  тогглами с тремя состояниями, массовые операции.
- Надёжное самообновление и корректное сравнение версий (dev.N — численно).

### Добавлено (v2 — удалённый режим, в разработке)
- Мультисервер: реестр серверов и кластеров; опрос ТОЛЬКО выбранного (при входе пусто), параллельно с таймаутами и пометкой недоступных.
- Панель серверов: кластеры + чекбоксы серверов (быстрый выбор кластером, тонкий — чекбоксами).
- Список с колонкой «Сервер», сортировка-тоггл по серверу.
- Массовые операции: чекбоксы строк, отключить/выход выбранным, «выбрать все отключённые»; при выделении просмотр/управление заблокированы.
- Импорт/экспорт кластеров, серверов и всего реестра файлом (слияние без потерь).
- Ресурсы: загрузка серверов (Zabbix или WMI) и ЦПУ/ОЗУ по сеансам; настройка Zabbix и переключатель показа.
- Удалённые действия/политика по серверу (нативно: quser/mstsc/tsdiscon/logoff, реестр через ConnectRegistry, задание через schtasks /s).
- Поддержка внешнего WebView2-рантайма (папка webview2/ рядом с exe) для старых Windows.

## [0.1.0] — 2026-08-27

### Добавлено
- Закреплённая шапка: прокручивается только список пользователей.
- Уведомление об обновлении внутри приложения (баббл): «Отложить» / «Не показывать»; канал dev видит и стабильные, и dev-версии.
- Исправлена проверка обновлений в собранном exe (добавлен certifi — HTTPS к GitHub падал с CERTIFICATE_VERIFY_FAILED).
- Поиск по имени (Enter, печать при активном окне), сортировка тремя кнопками-тогглами (имя/статус/простой), каждая в обе стороны.
- Кнопка-ссылка на файл журнала в футере.
- Память геометрии окна (размер, позиция, максимизация) между запусками.
- Надёжное самообновление на Windows с логом.
- Иконка приложения (exe + фавикон вебвью) из фирменного логотипа.
- Каркас приложения: список сеансов RDS, четыре действия на строке
  (просмотр/управление/отключить/выход), настройки с экстренным режимом
  политики и обновлением с GitHub.
